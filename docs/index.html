What it does

  • Generative faviconsA deterministic icon from any seed, with an optional self-drawing animation.
  • Badges and progressUnread counts or short text, a progress ring for builds and uploads, and a pulse when something needs attention.
  • Per-environment iconsdev, staging and prod each get their own icon, detected from the hostname with env: 'auto'.
  • Static favicon setsA CLI and Vite / Next.js helpers generate favicon.svg, favicon.ico, PNGs and a manifest per environment.
  • Small and safeUnder 3.1 KB min+gzip, zero dependencies, TypeScript types, ESM + CJS, SSR-safe, works without canvas.
  • Respects reduced motionAnimations show their final frame when the system prefers reduced motion.

Quick usage

API

import { favipulse } from 'favipulse';

const fav = favipulse({ seed: 'acme', env: 'auto' }); // dev/staging/prod detected from the hostname
await fav.draw();          // self-drawing intro (instant with reduced motion)

fav.badge(3);              // unread count; 0 hides, >99 shows 99+
fav.progress(0.42);        // progress ring (0-1 or 0-100)
fav.pulse();               // pulsing halo; fav.pulse(false) to stop
fav.reset();               // clear badge, progress, pulse

CLI

npx favipulse generate --seed acme --out public/favicons

Every option is documented in the favipulse docs.
