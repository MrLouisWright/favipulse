# favipulse

**Favicons that say something: who, where, and what's happening.**

favipulse is a tiny (2.9 KB min+gzip), zero-dependency, typed ESM + CJS favicon library by [Louis Wright](https://github.com/MrLouisWright):

- **Generative icons**: a deterministic identicon from any seed, with an optional self-drawing animation.
- **Badges, progress rings and pulse**: unread counts, build/upload progress, "needs attention".
- **Per-environment icons**: dev, staging and prod each get their own icon from the same seed.
- **Static sets**: a CLI (and Vite / Next.js helpers) that write `favicon.svg`, `favicon.ico`, PNG sizes and a manifest per environment.

It's the maintained replacement for favico.js (last release 2015) and tinycon (last release 2017).
